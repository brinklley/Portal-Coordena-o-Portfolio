# 0002 · Hierarquia e vínculos

**Contexto.** O portfólio é gerido em Iniciativa → Release → Épico → itens dos times.
**Decisão.** Vínculos por `Parent` entre os níveis de portfólio; do item de time ao épico, na ordem campo `ID_EPICO_UNICRED` → Parent (se for épico carregado) → Remote Related. Divergências vão para a Higiene; vale o campo.
**Consequências.** Times de organizações diferentes (vsunicred, campo) e da mesma organização (unicredbr/TI, Parent) funcionam juntos. Ver `docs/regras-de-negocio.md` §1.
